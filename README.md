One word a grandma would text about AI. This entry for make.fun's "One Word From Grandma" bounty writes the single word `smartypants` — the classic grandma word for a know-it-all — to `/output/entry.txt`.

## Run

```bash
python3 main.py
```

The program writes `smartypants` to `/output/entry.txt` (falling back to `./output/entry.txt` when `/output` cannot be written). It is deterministic, uses only the Python standard library, and needs no network access.
